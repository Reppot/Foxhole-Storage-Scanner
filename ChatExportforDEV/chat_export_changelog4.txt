=========================================================================
ЭКСПОРТ ЧАТА + ЖУРНАЛ ИЗМЕНЕНИЙ ДЛЯ ПРОГРАММИСТА
Проект: Foxhole Stockpiles -> Discord relay (relay.py)
=========================================================================

КОНТЕКСТ ПРОЕКТА
-----------------
relay.py — Flask-сервер, который принимает POST-запросы от мода
Foxhole Stockpiles (FS), рендерит содержимое склада (stockpile) в виде
картинок (Pillow/PIL, постранично по 12 строк) и отправляет их в Discord
через webhook. Для каждого предмета в стоке используется:
  - ITEM_NAMES_RU  (dict: код предмета -> русское название)
  - ITEM_ICON_FILES (dict: код предмета -> имя файла иконки в ICONS_DIR)
  - item_codes.py  — вспомогательный словарь авто-транслитерированных
    названий (fallback, если кода нет в ITEM_NAMES_RU)

Если код предмета отсутствует в словарях — рендерится "причёсанный"
английский код (prettify_code) и пустой квадрат вместо иконки.
Именно с поиска и устранения таких "дыр" начался весь тред.

    "DemolitionRocketAmmo" -> "RazrushayushchayaRaketa.png"

  НОВАЯ ПОДСИСТЕМА ЛОГИРОВАНИЯ нераспознанных предметов:
    - UNMAPPED_LOG_PATH = <папка со скриптом>/unmapped_items.log
      (переопределяется через переменную окружения UNMAPPED_LOG_PATH)
    - _unmapped_registry (dict в памяти процесса) — дедуп по коду
    - _record_unmapped(code, guess, qty, crated, stockpile, hex,
                        name_missing, icon_missing):
        * пишет строку в консоль с тегом "UNMAPPED_ITEM" (grep-able)

                     name_missing, icon_missing

      в лог единым блоком "=== НЕРАСПОЗНАННЫЕ ПРЕДМЕТЫ ===" —
      удобно целиком скопировать и прислать для разбора.
    - Новый роут GET /unmapped — отдаёт текущий registry в JSON
      без похода в файл.
    - _draw_item_row() дополнен параметрами stockpile_name/hex_display
      и теперь вызывает _record_unmapped() на каждой отрисованной
      строке.

      в /relay (и success, и error-ветка).

  Обновлена шапка-докстринг модуля с описанием, как читать логи.

ШАГ 3. РЕГРЕССИЯ — все иконки разом пропали
---------------------------------------------
Пользователь прислал unmapped_items.log, где ВСЕ без исключения
предметы (даже давно работавшие: GrenadeW, Revolver, Binoculars и
т.д.) имели icon_missing=true. Диагноз: полностью не находится папка
Icons — то есть проблема не в отдельных иконках, а в самом ICONS_DIR.
Причина — "портативный" дефолтный путь, введённый на Шаге 1, не
совпадал с реальным расположением папки на машине пользователя.

Исправление: ICONS_DIR и BACKGROUND_PATH возвращены на оригинальные
жёстко прописанные пути:
  BACKGROUND_PATH = r"D:\Games\foxhole-stockpiles-main\Foxhole-Storage\scr\gray-background.jpg"
  ICONS_DIR       = r"D:\Games\foxhole-stockpiles-main\Foxhole-Storage\Icons Foxhole\All\Storage\Unnamed\1\Icons"
(оба по-прежнему переопределяемы через переменные окружения
BACKGROUND_PATH / ICONS_DIR).

Пользователь подтвердил: реальный путь к папке иконок на его машине —
именно
  D:\Games\foxhole-stockpiles-main\Foxhole-Storage\Icons Foxhole\All\Storage\Unnamed\1\Icons
— совпадает 1-в-1 с восстановленным дефолтом.

Заодно по тому же логу добавлены ещё два кода (не техника, а
стационарные орудийные установки, по аналогии с уже существующим
EmplacedInfantryW; иконок под них в Icons.zip нет):
  ITEM_NAMES_RU (добавлено):
    "EmplacedATW"             -> "стационарная противотанковая установка"
    "EmplacedLightArtilleryW" -> "стационарная лёгкая артиллерийская установка"

Итоговый relay.py на этом шаге зафиксирован как рабочая версия.

ШАГ 4. Нарезка иконок техники из скриншотов игрового UI
----------------------------------------------------------
Пользователь прислал 4 скриншота вкладки СКЛАД -> ТРАНСПОРТ (сетка
иконок техники с подписями) и попросил аккуратно нарезать иконки и
пронумеровать.

Метод:
  - Автоматическое детектирование границ сетки по тёмным
    разделительным линиям (анализ яркости построчно/постолбцово,
    numpy), т.к. ширина/высота ячейки не всегда чётко следует из
    размеров скриншота.
  - Итоговый размер ячейки ~72x72 px, 8 колонок в каждом скриншоте,
    4-5 строк в зависимости от скриншота.
  - Пустые слоты (полностью однородный цвет, std яркости < 6)
    пропущены — таких оказалось 3 (в 4-м скриншоте).
  - Итого нарезано 117 иконок (icon_001.png ... icon_117.png),
    нумерация сквозная по всем 4 скриншотам, порядок чтения —
    слева-направо, сверху-вниз.
  - Каждая иконка = вся ячейка целиком (картинка техники + подпись
    снизу), т.к. подпись является частью UI-ячейки.
  - Сформирован manifest.csv (номер, исходный скриншот, строка,
    колонка, координаты выреза) для трассируемости.
  - Результат: icons_cropped.zip

Отдельным запросом пользователь попросил список названий техники —
сформирован по подписям на иконках (vehicle_names.txt, 117 строк,
формат "NNN Название"). Две позиции (068, 069) на 3-м скриншоте были
без подписи в игре — отмечены как "(без подписи — силуэт танка)";
позже пользователь сам дополнил эти две позиции названиями:
  068 -> HA1-Sagaris
  069 -> Sharkey-Devitt Birdeater Mk. I
